## 원래 흐름에서의 고장 위치

기록 버튼 → `setTab('history')` → `Er()` → `Wt()` → `e.items.length` / `e.history.map(...)`.

여기서 예외가 나면 이를 잡는 화면 경계가 없습니다. 잘못된 식탁 항목은 `Ge()`의 `completeMeals()`에서 존재하지 않는 식품의 이름·단위를 읽다가 오류를 낼 수도 있습니다. 프로필의 `targets`나 알레르기 목록 형태도 검사되지 않았습니다.

대시보드는 원래 별도 탭이 아니라 `home`으로 이동하며 `setDash`를 실행합니다. 뮤즈의 홈 꾸미기·대시보드 숨김 의도와 분리되어 있지 않았습니다.

## 검증 제한

실제 Gemini·결제 요청은 하지 않았습니다. API·로그인·결제·카메라·음성 검색의 종단 간 동작은 미검증입니다. 기존 공개 키는 소유자가 사용 상태를 확인하고 필요하면 회수해야 합니다. 이 작업에서는 키를 사용하거나 회전하지 않았습니다.
